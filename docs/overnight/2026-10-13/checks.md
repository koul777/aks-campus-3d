## 모바일 화질 추가 수정

- 원인: Cesium의 기본 `useBrowserRecommendedResolution=true`는 DPR을 무시하는데 기존 코드가 `resolutionScale=1.5/DPR`까지 적용. DPR 3의 390×774 CSS 캔버스를 **195×387**로 렌더함.
- DPR을 명시적으로 반영하고 최대 2배·240만 픽셀 예산을 적용(CSS 1배는 유지). 같은 화면에서 **780×1548** 확인. 기존 렌더 대비 가로·세로 각각 4배, 총 픽셀 수 16배. 지면 영상의 원본 해상도를 높인다는 뜻은 아님.
- 화면 크기 변경 시 해상도 재계산, 모바일 시설명 사각형 겹침 완화, 선택 시설 우선 표시, 터치용 조작 안내.
- 390×844, DPR 3과 844×390 가로 전환에서 해상도 유지·넘침 없음. 데스크톱·모바일 레이어/재생/일시정지/추적 검사 통과. 준비 27.4초·10.1초, 이동 25.4fps·25.4fps, 정지 추가 렌더 0·1회. 다른 작업과 함께 실행한 세션의 관측값으로 실제 휴대전화 성능 측정이 아님.
- 근거: `mobile-quality/results.json` 및 실제 개선 전후 PNG, `interaction-check/results.json`. README에 실제 비교 이미지 포함.
