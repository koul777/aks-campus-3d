# Phase21 실제 화면 검토

2026-10-10 Astra. `artifacts/north-haku-review-phase21-retry`의 학의정 4장, 국은관·진현관·운중관 product/side 6장을 직접 열람했다. 앞서 직접 열람한 Phase20 학의정과 공식 hak01–03, 공식 국은관·진현관·운중관 사진 및 하부 확대와 대조했다. 소스·데이터·지형·빌드 변경 없음.

## 학의정

**서까래 관통 수정은 실제 화면에서 확인된다.** Phase20처럼 지붕 윗면을 가로질러 길게 튀어나오는 목재가 close/product/corner에서 보이지 않는다. 처마 끝의 목재 단면과 하부 구조가 남아 있으며 코너에서도 지붕 면을 덮는 긴 서까래가 없다. root의 위쪽 관통 정점 0 검사는 이 관찰을 보조하는 별도 수치 근거다.

현재 황갈색 단색 목재는 기각한 탈색 목리 trial보다 원본의 큰 색 범위에 가깝지만 실제 부재별 결과 옹이·그늘은 재현하지 못한다. 난간의 회문 방향 특징은 보이나 원본 hak02/03의 더 복잡한 선형 결구를 간략화했다. 지붕 골/용마루, 목재 연결부는 여전히 추정 형상이다. `underside`라는 파일도 실제 시선은 지붕 아래를 충분히 올려다보는 극근경이 아니어서 전체 지붕 안쪽 결구의 정합성까지 검증한 것은 아니다.

## 세 건물의 전면 지면

국은관·진현관·운중관 모두 기존의 큰 회색 전면 스커트가 줄었다. 하층 창과 문이 드러난 상태로 지면이 기단 가까이 올라와 공식 사진의 잔디 비탈/낮은 기단 관계에 더 가깝다. 국은관의 긴 여러 단 계단, 진현관의 짧은 계단, 운중관의 넓은 접근 계단이 구분된다. 새로 흙이 하층 창을 덮는 현상은 해당 캡처에서 보이지 않는다.

다만 위성 영상이 늘어나 보이는 비탈과 실제 잔디·석재 옹벽은 서로 다르다. 측면 일부 회색 스커트도 남아 있으며 사진 밖 후면/측면을 정확히 복원했다고 할 수 없다. root가 보고한 계단 발치 지면 차이 국은관 약 .13m/운중관 약 .16m는 미해결 접합 차이로 남긴다. 이 캡처 해상도만으로 그러한 차이가 완전히 없다고 판단하지 않는다.

## 운중관 사선 창 가림: 후속 확인 필요

`unjung-product.png`에서는 전면의 상하 창이 보이지만 `unjung-side.png`에서는 같은 전면 창 대부분이 흰 벽으로 소실되고 문과 측면 창은 남는다. 이 시점 의존 차이는 유리 색 문제가 아니라 후퇴한 회랑벽/창 plane 깊이·가림 가능성을 먼저 확인해야 한다. 현재 지면 변경과 독립적으로 root/Sol에 전달했다. 원인을 확인하기 전 전체 입면 회귀 없음으로 판정하지 않는다. 국은관·진현관은 side 화면에서 돌출 창의 옆 면이 조금 더 드러나지만 실사 쌍창 경사의 정확한 치수 일치는 여전히 미확정이다.

## 다음 시각 개선 하나

운중관 창 가림 결함을 우선 해결한 뒤, **한국학대학원 남면의 원본에서 가려지지 않은 동쪽 창군 2개만 실제 사진의 상·하 유리 외관 색으로 구분하는 제한 시험**을 권고한다. 이미 확보한 4032px `target-223408506698-19.jpg`에서 상층 윗유리는 어두운 실내/블라인드, 아랫유리는 파란 하늘·수목 반사로 나뉘며 하층은 옅은 녹색 블라인드가 보인다. 현재 같은 짙은 유리색으로 읽히는 부분과 차이가 크고, 기존 본관5와 같은 픽셀 평균 기반 계약을 재사용할 수 있다.

위치는 기존 windowLayouts의 동쪽 2개 bay와 각 transom pane으로 제한하고 사진의 수목/표지석으로 가린 영역은 제외한다. 실제 색 표본을 취한 뒤 locators를 확인하며 건물 전체에 복제하지 않는다. 우선 색 분류만 적용하고 블라인드 줄수나 반사 나무 그림을 발명하지 않는다. 이 제안은 실제 반사 환경 복원이 아니라 특정 사진 시점의 제한적 외관 추정이며, 현재 문서에서는 데이터나 색을 만들지 않았다. 새로운 지형/수면 기능보다 근거와 검수 범위가 좁고 재사용 구현이 가능하다.
