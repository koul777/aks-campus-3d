# 본관 네 전정수목 형태 계약 검토

2025 본관 원본 `blog-20250410_135911.jpg`와 `foliage-source/tier-crown-contract.json`을 대조했다. 중앙 계단 양쪽의 큰 두 개와 바깥쪽 작은 두 개가 사진에서 각각 확인된다. 다른 낙엽수와 낮은 화단 관목을 이 네 수목으로 대체하지 않는다.

사용할 후보는 landscape.ts의 main-south-west-small-pruned, west-large-pruned, east-large-pruned, east-small-pruned 네 개다. 존재는 사진 근거지만 위치는 각각 약3m 불확실성을 가진 추정이다. 측량된 배치가 있다는 문구를 사용하지 않는다.

큰 두 수관은 약4단의 둥근 덩어리가 겹치며 위로 점차 좁아진다. 독립 원반을 쌓거나 뾰족한 원뿔로 만들지 않는다. 작은 두 수관은2~3개 둥근 덩어리와 조금 더 뚜렷한 허리가 있지만 완전히 분리된 공중 구체는 아니다. 잎 표면의 잔요철과3~6% 변화율은 생성 방식의 추정이며 실제 개체를 측정한 값이 아니다. 수종을 확정하지 않는다.

기존 후보 높이/수관폭을 우선한다. 서쪽 큰 개체6.5/5.2m, 동쪽 큰 개체6.4/5.0m, 서쪽 작은 개체3.6/3.4m, 동쪽 작은 개체3.8/3.5m다. 이 역시 사진 비례 추정이며 template의6.5/3.6m로 모든 개체를 동일하게 덮어쓰지 않는다. 원근 때문에 수관 깊이는 특히 불확실하다.

위치는 수정된 본관 둔덕의 실제 표면에서 샘플한다. 줄기가 공중에 뜨거나 건물 처마에 수관이 관통하면 나무 높이만 줄여 숨기지 말고 지면 접합·거리 추정을 함께 검토한다. opt-in 시범으로만 생성하고 본관 정면 실제 렌더에서 네 개체의 좌우 순서·수관 겹침·건물 베이 가림을 확인한 뒤 채택을 판단한다.
