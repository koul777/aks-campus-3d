# 한국학중앙연구원 — Cesium 실제 지도 시제품

실제 위성영상과 고도 지형 위에 공식 안내도의 19개 시설을 표시합니다. 본관, 강당, 국은관, 동편연못, 청계관, 진현관, 운중관, 식당/매점, 한국학도서관, 학의정, 청계학당, 이택재, 한국학대학원, 보인재, 시습재, 문형관, 장서각, 지하주차장, 정문을 포함합니다. 공식 안내 서비스가 아닙니다.

## 실행

이 PC에서는 바탕화면의 **한국학중앙연구원 3D 캠퍼스** 바로가기를 두 번 누르면 됩니다. 로컬 서버가 꺼져 있으면 자동으로 다시 시작하고 기본 브라우저를 엽니다. 기존 `AKS` 바로가기는 별도 기관 프로그램이므로 이 캠퍼스 앱과 관계없습니다. 실행 로그는 `artifacts/runtime`에 저장됩니다.

Node.js 24 환경에서 확인했습니다.

## GitHub와 Vercel 배포

소스 저장소는 [koul777/aks-campus-3d](https://github.com/koul777/aks-campus-3d)입니다. Vercel은 Node.js 24에서 `npm ci`로 설치하고 `npm run build`의 `dist` 결과물을 제공합니다. Cesium Workers·Assets·ThirdParty·Widgets는 설치와 빌드 과정에서 생성됩니다.

실행에 필요한 사진·재질·모델은 `public`에 포함합니다. 대용량 조사 원본 `references`, 검수 산출물 `artifacts`, 품질 검토 스냅샷 `.assay`는 로컬에 보관하며 Git과 배포 업로드에서 제외합니다. 해당 로컬 파일을 참조하는 과거 검수 스크립트와 문서의 재검토에는 원래 작업 폴더가 필요합니다.

```sh
npm install
npm run dev
npm run build
npm run preview
```

설치 및 빌드 스크립트가 Cesium Workers, Assets, ThirdParty, Widgets를 `public/cesium`에 복사합니다. 기본 실행에 API 키 또는 Cesium ion 계정이 필요하지 않습니다. 지도 자료를 불러오기 위해 인터넷 연결이 필요합니다.

## 자료와 표현 범위

- 실제 지도: CesiumJS 1.146.0, Esri ArcGIS World Imagery 위성영상.
- 지형 기본 자료: AWS Terrain Tiles / Mapzen Terrarium 약 30m DEM. RGB 고도를 미터 단위로 복호화하며 레벨14를 넘는 일반 지역은 원자료를 보간합니다. 연못 바닥·주차장 옹벽 접점·본관 앞 둔덕·문형관 북동 앞마당·학의정 착지·국은/진현/운중 전면은 사진에서 해석한 좁은 구간만 시각적으로 보정합니다. 레벨17–19의 추가 격자는 이 추정 접합을 표현하며 실측 해상도를 높인 자료가 아닙니다. 보정 범위와 출처는 `src/data/site-grading.ts`와 `src/terrain-grading.ts`에 기록합니다.
- 위치와 윤곽: OSM 지리 윤곽 및 실제 위성영상 교차 해석. `src/data/geographic-buildings.ts`가 anchor, 방위, 날개별 평면·높이·지붕·사진·검증 상태의 단일 기준입니다. 평면은 anchor 기준 ENU 미터이며 실제 위경도로 변환해 배치합니다.
- 건축 형태: 공식 사진에서 해석한 깊은 처마, 경사지붕, 다중 날개, 중정, 창 배열, 열주. GLB 모델을 생성해 실제 DEM에서 읽은 고도에 배치합니다. 높이·지붕·창문·기둥의 상세 치수는 근사치이며 사진측량이나 정밀 디지털 트윈이 아닙니다.
- 비건물 시설: 연못의 수면과 흰 아치다리, 학의정의 열린 목조 정자와 받침 기둥, 지하주차장의 낮은 진입 옹벽·두 출입구·포장면을 별도 형태로 표현합니다. 지하주차장의 전체 지하 공간을 지상 건물로 만들지 않습니다.

공식 번호 순으로 19개 시설을 선택할 수 있습니다. 선택 시 정면에 가까운 낮은 사선으로 이동하고 공식 사진을 시설 목록 위에서 비교할 수 있습니다. 전체 보기에서는 위경도 범위와 화면 비율에 맞춰 캠퍼스를 표시합니다. 학의정 등 수목에 가린 시설의 위치는 안내도와 주변 랜드마크를 교차 해석했으며 확인 상태를 데이터에 명시합니다.

관련 원본: [공식 캠퍼스 안내도](https://www.aks.ac.kr/com/cmm/EgovContentView.do?lang=kor&menuNo=5010182000), [Cesium 지형 API](https://cesium.com/learn/cesiumjs/ref-doc/CustomHeightmapTerrainProvider.html), [Terrarium 고도 형식](https://github.com/tilezen/joerd/blob/master/docs/formats.md). 화면 하단에서 지도 제공자의 저작권 표기를 유지합니다. 건물별 사진과 OSM 출처를 시설 정보에서 확인할 수 있습니다.

지도 드래그로 이동하고 휠·우클릭으로 확대합니다. Ctrl+드래그로 회전하거나 입체 / 위에서 / 회전 / 확대·축소 / 캠퍼스 전체 버튼을 사용하세요. 시설 목록을 선택하면 해당 건물로 이동합니다. 건물 모델을 끄면 위성영상 원본과 배치를 비교할 수 있습니다. 모바일은 지도부터 표시합니다. 카메라 버튼은 즉시 이동하며 애니메이션을 사용하지 않습니다.

## 구조와 검토

`Scene.tsx`는 Cesium을 지연 로드합니다. 초기 모델·지도와 최종 전체 시점을 준비하는 동안 연속 렌더링하고, 준비 후에는 화면 변경이 있을 때 렌더링합니다. 선택 위치의 지형 확인 동안 다시 연속으로 전환하며, 명시적인 종료 타이머와 입력 정리로 복귀합니다. `render=continuous`는 비교용 연속 렌더 옵션입니다. 글꼴은 로컬 한국어 글꼴을 사용하고 외부 글꼴 다운로드를 요구하지 않습니다. `building-model.ts`는 실제 배치 데이터의 날개별 평면을 GLB 본체·경사지붕·창·기둥으로 변환합니다. `terrain.ts`는 실제 고도 자료를 캐시하고 해석하며 최대 지형 레벨을 명시하여 그 이후는 실고도 자료를 보간합니다. 자료 실패와 WebGL 오류는 화면에 표시합니다. 로그인·DB·실내·1인칭·외부 배포는 포함하지 않습니다.

학의정은 2021년 사진의 사각 정자와 곡선 처마를 참고한 지붕·흰 기초·회문 난간·서까래를 표현합니다. 곡률과 부재 치수는 사진 추정입니다. 실제 출력 GLB의 지붕/목재 관통 검사를 별도로 수행하며, 이것이 전통 결구나 실제 치수의 정확성을 인증하지는 않습니다. `hakuRoof=legacy`로 이전 직선 지붕을 비교할 수 있습니다.

학의정 서까래는 지붕 삼각망 교차점까지 포함한 모든 원본 표본을 검증해 위쪽 편차 없이 최대 2mm 아래로만 변하는 축약 형상을 기본으로 사용하며, `hakuGeometry=legacy`로 이전 전체 표본 형상을 비교할 수 있습니다.

학의정 출입면의 현판은 2024년 고해상도 원본 사진에서 글자와 테두리를 투영해 표현합니다. 현판 영역은 약212–218×125–133px이며 위치·크기는 추정입니다. 원본 JPEG를 수정하거나 글자를 다시 쓰지 않았습니다. `hakuPlaque=legacy`로 현판 없는 이전 표현을 비교할 수 있습니다. 선택 시 추정 출입면을 낮은 시점에서 보여줍니다.

학의정 진입부는2024·2026년 공식 사진에 보이는 짧은 석재 발판2개와 더 넓은 벽돌 포장으로 수정했습니다. 종전 긴 진입판을 제거하고, 계단·포장 받침과 물가의 지형을 함께 연결했습니다. 발판 높이·치수·포장·물가는 사진 비례 추정입니다. 수정 후 실제6개 구도와19시설 전체 기능을 검수했으며, 목재·조각·주변 물가를 실물과 동일하게 복원했다는 뜻은 아닙니다. 근거와 독립 검토는 `docs/continuation/2026-10-10/haku-access-source-review.md`에 있습니다.

검수용 `?diagnostics=1`에서는 공개 Cesium API로 모델 준비와 지면 고도·카메라 상태를 확인할 수 있습니다. `photoPatches=1`, `landscape=1`, `materials=1`, `glass=environment`, `wood=source`, `wood=normal`, `wood=tinted`, `water=translucent`는 비교 시험으로 기본값이 꺼져 있습니다. 실제 비교에서 개선이 확인되지 않은 후보도 기록을 보존합니다. 기와 중립색·연속 UV·약한 겹침선과 본관 상부 유리 5곳의 제한적 관측색은 기본 채택했습니다. `roof=legacy`, `roofUV=legacy`, `roofPattern=legacy`, `glass=legacy`, `glassPattern=legacy`로 이전 표현을 비교할 수 있습니다. 원본 사진의 URL·촬영/게시일 구분·해시는 `references/research-20261010`에 보존합니다.

보인재는 두 동과 낮은 연결부를 함께 포함하는 모델 경계로 화면 비율에 맞춰 선택 시점을 잡습니다. 국은관·진현관 돌출창은 앞뒤 모서리 기둥 사이로 옆 유리가 보이도록 수정했습니다. 확인되지 않은 외벽이나 높이를 실측값으로 간주하지 않습니다.

대학원 현관의 지붕 아래 막힌 본체와 지붕 위 잘못된 보를 제거하여 열린 차양으로 표현합니다. `graduateEntry=legacy`로 이전 막힌 모델을 비교할 수 있습니다. 현관 기둥의 단면·계단 정렬·지면 접합은 아직 추정이며 실제 사진과 차이가 남아 있습니다.

7시간30분 작업의 실제 시작·한도·체크포인트는 `docs/overnight/2026-10-10/session.md`와 `checks.md`, 최종 전달 상태와 남은 작업은 `handoff.md`에 기록합니다. 실행 오류가 없는 것과 사진과 동일한 외형을 달성한 것은 별도로 판정합니다.

GPT-6 Astra: 지리 윤곽·사진 해석, 모델 형상·화면 설계, 구조 검토. GPT-6.1 Sol: 구현, 일반 수정 및 빌드. 이전 미니어처 시제품의 화면 검증은 현재 Cesium 결과의 검증으로 간주하지 않습니다. 현재 결과의 실제 위성 배치와 모바일·데스크톱 화면은 별도로 검수합니다.
